# たこあげ ちゅうごくご（v1.2）

『标准中文（修订版）第一册』（人民教育出版社）に沿って、日曜のレッスンで習った課を平日に5分ずつ復習する子ども向けPWAです。

## ファイル構成（サブフォルダなし・全8ファイル）
- index.html … アプリ本体（課データ・生字・書き順データ・書き順ライブラリをすべて内蔵）
- manifest.json … ホーム画面追加用の設定
- sw.js … オフライン用のService Worker
- icon-180.png / icon-192.png / icon-512.png … アイコン
- README.md … このファイル
- LICENSES.txt … 同梱ライブラリ・データのライセンス

## 公開とインストール
1. GitHubのリポジトリで「Add file」→「Upload files」を開き、8ファイルを全部選んでまとめてアップロード（フォルダごとではなく、中のファイルを選ぶ）
2. Settings → Pages → Branch を main / root にして保存
3. iPhoneのSafariでURLを開き、共有 →「ホーム画面に追加」

注意：個人アカウント（Free / Pro）のGitHub Pagesは、リポジトリを非公開にしても**サイト自体はURLを知っていれば誰でも見られます**。アクセス制限はGitHub Enterprise Cloudの機能です。
このアプリには教科書の本文・歌・挿絵は入れていないので、推測されにくいリポジトリ名にしておけば実用上は問題ありません。

## 音声（重要）
iPhoneの読み上げ機能で中国語を再生します。中国語の声が入っていないと再生されません。
設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 中文（中国大陆）の声を追加してください。
アプリ内「おうちのかたへ」→「音声の確認」で、使われている声を確認できます。

## 毎週の使い方
1. 日曜のレッスン後、「おうちのかたへ」（足し算で開く）→「こんしゅうの課」を変える
2. 平日、ホームの「れんしゅう する」から
   - 🎴 カードで きく：単語を音声で聞く（全部見ると★）
   - 👂 きいて えらぶ：聞いて絵を選ぶ6問（当課の語＋前の課の復習）
   - 🧩 ならべて ぶん：聞いた順に語を並べる
   - 🦜 まねっこ：お手本→録音→自分の声で聞き比べ→親が「いえた！」
   - ✍️ かんじを かこう：その課の生字の書き順アニメ→指でなぞり書き（全部書けると★）
3. ★3つで、その課のたこが一番高く上がる

## データを更新するとき
index.html の `LESSONS` の各課に、単語を1行ずつ追加します。
`W(漢字, ピンイン, 意味, 絵文字, カナ目安, 絵で出題するなら1, 出典)`
出典は v=词语表で確認済み / t=課タイトル・基本句のみ（未照合） / x=补充词语表 / n=人名。
更新したら sw.js の `CACHE` の版数を上げてください（例: takoage-v0.9 → v1.0）。上げないと古い版が表示されることがあります。

## 限界
- 読み上げの声調は完璧ではありません。気になる語は先生に確認してください。
- 「練習用に追加」の文（我家有四口人。など）は教科書にはありません。
